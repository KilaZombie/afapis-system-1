# AFAPIS System 1 MVP

Phoenix local-service lead-generation prototype for dryer vent and air duct cleaning.

## Current state
- Static site ready for free static hosting.
- Educational pages for both services.
- Lead qualification form.
- Test submissions stored only in browser localStorage.
- No contractor receives test submissions.
- No Google Business Profile is used for the lead-gen entity.

## Before public launch
1. Choose a public brand/domain/subdomain.
2. Replace placeholder privacy/terms with reviewed production copy.
3. Connect the form to a real backend and lead database.
4. Implement auditable consent records.
5. Recruit and vet initial contractor buyers.
6. Define lead acceptance, pricing, routing, refunds, and dispute rules.
7. Add analytics and conversion tracking.
8. Test end-to-end with controlled leads.

## Acquisition rule
Do not create a fake Google Business Profile for the lead-generation entity. Google lists lead-generation agents/companies as ineligible for Business Profiles.

## Search rule
Do not mass-publish thin AI pages. Pages must provide original, useful local information and be created for users, not merely search manipulation.
